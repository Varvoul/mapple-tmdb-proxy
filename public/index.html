Mapple TMDB Proxy

Vercel serverless proxy for mapple.fun's TMDB API. Auto-domain discovery, 2-hour TTL cache, combined detail endpoints.

Available Endpoints

GET /api/tmdb/<path>?<params>
Generic Proxy Passes through to any TMDB endpoint. Supports all params (language, page, query, with_genres, append_to_response, etc.). 2h cache.
GET /api/details/movie/{tmdb_id}
Combined Returns metadata + cast_crew + pictures + external_ids + statistics + recommendations + similar + videos + watch_providers + keywords in one call.
GET /api/details/tv/{tmdb_id}
Combined Returns metadata + cast_crew + pictures + seasons + external_ids + statistics + keywords + videos + reviews. Add ?expand_seasons=true to fetch each season's full episode list.
GET /api/health
Debug Returns current mapple domain, auth status, cache stats.

Example calls

fetch('/api/tmdb/movie/popular?language=en-US&page=1')
fetch('/api/tmdb/discover/movie?with_genres=28&primary_release_date.gte=2025-01-01&sort_by=popularity.desc')
fetch('/api/details/tv/1396?expand_seasons=true')
fetch('/api/details/movie/574475?language=en-US')
